# leahnicolich.com

Static portfolio site for artist Leah Nicolich. The site is designed for GitHub Pages and preserves the legacy Squarespace routes through `404.html` redirects.

## Local preview

Serve the repository root with any static file server, then open `index.html` through that server.

## Contact form

Set `contactEmail` at the top of `app.js` before launch. The form prepares a message in the visitor's email application; no form data is stored by the site.
